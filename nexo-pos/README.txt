NEXO POS — installable offline app
===================================

OPEN / DOWNLOAD:  https://fintrakpro.github.io/nexo-pos/
Tap the "DOWNLOAD APP" button at the top of the app and follow the steps.

This is the complete app: same screens, design, formulas and features as
your NEXO POS page (register, barcode scanner, products and stock lots,
restock planning, suppliers, cash lend and Pa orders, utang and installments,
customers, staff PINs and roles, dashboard, reports in PDF and Excel, monthly
insights, receipts by print, picture, WhatsApp, Telegram and Gmail).
It works without internet. Data is saved on each device.


INSTALL ON EACH DEVICE
----------------------
  Android (Chrome): open the link → DOWNLOAD APP → Install now
                    (or menu ⋮ → Install app).
  iPhone/iPad (Safari): open the link → Share → Add to Home Screen.
  Windows/Mac (Chrome or Edge): open the link → DOWNLOAD APP → Install now
                    (or the install icon at the right of the address bar).

After the first open, it starts and works with no internet.


BRING IN YOUR CURRENT STORE DATA
--------------------------------
  Open the app → Settings → Data → Restore from backup →
  choose NEXO-POS-backup-2026-10-24.json
  (60 products, 13 sales, 3 utang accounts, 2 customers, 3 suppliers,
  staff "Christian" with his same PIN, store settings for ALFA STORE).


KEEP YOUR DATA SAFE
-------------------
  * Each device has its own records. Use one main counter device for sales.
  * Download a backup every day: Settings → Data → Download backup.
    Save it to Google Drive or email it to yourself.
  * To move to a new phone: back up on the old one, restore on the new one.
  * Do not clear the browser's site data for the app link — that erases it.


HOSTING IT YOURSELF (optional)
------------------------------
  The "app" folder can be put on any https host (Netlify Drop:
  drag the folder onto https://app.netlify.com/drop). To push an update,
  replace the files and change the VERSION line at the top of sw.js.
